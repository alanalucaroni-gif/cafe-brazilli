# Café Bazilli — Cold Brew

Site imersivo do Café Bazilli, com foco no Cold Brew de Café Especial sabor limão — edição comemorativa de 20 anos.

## Experiência

- Hero interativo com lata transparente centralizada
- Rotação da lata controlada pelo movimento do mouse
- Transição e troca de ângulos conforme a rolagem
- Segunda tela escura com resumo do produto
- Terceira tela clara com origem, edição e informações da embalagem
- Layout responsivo para desktop e celular

## Executar localmente

```bash
npm install
npm run dev
```

## Gerar versão de produção

```bash
npm run build
```
